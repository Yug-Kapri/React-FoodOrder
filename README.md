# 🍔 React Food Order App

A simple and modern **food ordering web application** built with **React**.  
This project demonstrates how users can browse meals, add them to a cart, and place an order in an interactive UI.

---

## 🚀 Features

- 📖 Browse a list of delicious meals  
- ➕ Add / Remove meals from the cart  
- 🛒 Real-time cart updates  
- 📦 Place an order with user details  
- ⚡ Built with **React Hooks** and **Context API**  
- 🎨 Styled with **CSS / Tailwind (if you used)**  

---

## 🛠️ Tech Stack

- **React.js** – Frontend framework  
- **React Context API** – State management  
- **JavaScript (ES6+)**  
- **CSS / Tailwind** – Styling  
- **Netlify** – Deployment
